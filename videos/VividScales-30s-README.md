# VividScales — 30-second landscaping ad

[Download the MP4](VividScales-Landscaping-30s.mp4) · [Editable project ZIP](VividScales-30s-Remotion-Source.zip) · [Timed narration script](VividScales-30s-Narration.md)

1080×1920 portrait, 30 fps, 900 frames, exactly 30.000 seconds. H.264 video with AAC music and original sound effects. The existing 5-second video is preserved.

The complete editable Remotion source also lives at the repository root. Run `npm ci`, `npm run dev`, and select `VividScalesAd`. Export with `bash scripts/render-ad.sh`.

The ad follows Alex's fictional landscaping inquiry from arrival through job details and estimate follow-up, ending with one CTA: **Book your free demo.** The URL is exactly `vividscales.com`.

**Production limitations:** Natural commercial voice generation was unavailable, so there is no voiceover. The exact 61-word timed narration script is included. Audio levels and encoding were checked, but live speaker audition was unavailable.

**S3–S6 are proposed demonstrations for review.** Responding to inquiries, collecting job details and estimate follow-up could not be verified against authoritative VividScales offer materials. No actual offer documentation was supplied, and the environment proxy blocked the official website. All fictional interfaces carry “Example workflow.” No automation, integration, team, deployment, sales-result or revenue claims are added.

The existing logo cutout is used proportionally and unchanged. The original attachment bytes were not available for a pixel-by-pixel comparison.
